Types of Numbers

  • Natural Numbers: 1, 2, 3, 4, 5... (counting numbers)
  • Whole Numbers: 0, 1, 2, 3, 4... (natural numbers + zero)
  • Integers: ...-3, -2, -1, 0, 1, 2, 3... (whole numbers + negatives)
  • Rational Numbers: Numbers that can be expressed as p/q (e.g., 1/2, 0.75, 3)
  • Irrational Numbers: Numbers that cannot be expressed as fractions (e.g., π, √2)

🎯 Decimal Comparison Trick

To compare decimals:

  • Compare digit by digit from left to right
  • 0.5 vs 0.45 → Compare first decimal place: 5 > 4, so 0.5 is larger
  • 0.234 vs 0.24 → Add zeros: 0.234 vs 0.240 → 4 > 3, so 0.24 is larger

🎯 Shortcut: Decimal Comparison Trick

Quick Method:

  1. Write all numbers with same decimal places (add zeros)
  2. Compare left to right, digit by digit
  3. First different digit determines which is larger
Example: Compare 0.6, 0.58, 0.605
→ 0.600 vs 0.580 vs 0.605
→ First decimal: all have same (5 or 6)
→ 0.6 (600) is largest, then 0.605, then 0.58

🌱 Living vs Non-living Things

Living Things (MRS GREN):

  1. Movement – Can move (animals) or grow towards light (plants)
  2. Respiration – Breathe/take in oxygen
  3. Sensitivity – Respond to environment
  4. Growth – Increase in size
  5. Reproduction – Make babies/seeds
  6. Excretion – Remove waste
  7. Nutrition – Need food/water
Examples:
Living: Dog, Tree, Bacteria, Mushroom
Non-living: Rock, Water, Sun, Car
Tricky: Virus → Not fully living (cannot reproduce alone)

💎 Core Mission – Understanding Percentages

20 min

What is Percentage?

  • Percent (%) = Per 100 → Out of 100 parts
  • 50% means 50 out of 100
  • 25% means 25 out of 100
  • 100% means complete/whole

🎯 Real-Life Example (Money)

  • You have ₹100
  • You spend 20% on food
  • 20% of ₹100 = ₹20
  • Money left = ₹100 - ₹20 = ₹80

Quick Understanding

  • 10% = 10/100 = 0.10
  • 25% = 25/100 = 0.25 = 1/4
  • 50% = 50/100 = 0.50 = 1/2
  • 75% = 75/100 = 0.75 = 3/4

⚡ Converting Between Forms

  • Fraction to %: Multiply by 100 (e.g., 1/4 × 100 = 25%)
  • % to Fraction: Divide by 100 (e.g., 20% = 20/100 = 1/5)
  • % to Decimal: Divide by 100 (e.g., 35% = 0.35)

⚔️ Practice Arena – Percentages

20 min

1. What is 25% of 200?

25% = 25/100 = 1/4. So 1/4 of 200 = 200 ÷ 4 = 50

2. Convert 3/5 to percentage:

3/5 × 100 = (3 × 100)/5 = 300/5 = 60%

3. If 20% of a number is 40, what is the number?

If 20% = 40, then 100% = (40 × 100)/20 = 4000/20 = 200

4. What is 10% of 500?

10% = 10/100 = 1/10. So 1/10 of 500 = 500 ÷ 10 = 50

5. 0.75 expressed as percentage is:

0.75 × 100 = 75%

⚡ Reasoning Power-Up – Number Series

5 min

🧠 Number Series Basics

Find the Pattern:

  1. Look at the difference between consecutive numbers
  2. Check if difference is constant (e.g., +2, +3, +5)
  3. Check if ratio is constant (e.g., ×2, ×3)
Example 1: 3, 6, 9, 12, ?
→ Difference: +3 each time
→ Next number: 12 + 3 = 15

Example 2: 2, 4, 8, 16, ?
→ Ratio: ×2 each time
→ Next number: 16 × 2 = 32
